# **App Name**: TripBook Pro

## Core Features:

- Secure Multi-Role Access: Enterprise-grade authentication system using Firebase Auth with partitioned dashboards for Transporters and System Admins.
- Unified Logistics Ledger: Comprehensive trip management engine for tracking vehicle logs, goods descriptions, and complex freight metrics across the fleet.
- Smart Counter Registry: Stateful tracking of Party and Client data synchronized with high-concurrency LR and Billing number sequence generators using Firestore transactions.
- Live Freight Calculator: Dynamic financial calculation tool that updates total freight, unloading charges, advances, and balances in real-time.
- Dynamic Print Preview Engine: Automated generation of pixel-perfect, print-ready LR receipts and tax-compliant billing invoices with specialized print-friendly CSS formatting.
- Administrative Insight Command: Global oversight module allowing admins to monitor aggregate revenue, pending balances, and total operational throughput across all registered companies.
- AI Freight Strategy Tool: Generative AI tool that analyzes route descriptions and cargo loads to suggest optimized rate strategies and logistical notes.

## Style Guidelines:

- Primary color: Electric Indigo (#5850EC), selected to evoke a sense of digital efficiency and logistical precision.
- Background color: Deep Midnight (#0C0B18), a highly desaturated navy that provides a high-contrast foundation for a premium SaaS aesthetic.
- Accent color: Azure Blue (#2563EB), an analogous shade that creates depth and clarity for actionable components.
- A refined pairing of 'Space Grotesk' for bold, machined-feel headlines and 'Inter' for crisp, high-legibility body text.
- Lucide-react icons used sparingly with thin stroke weights (1.5px) for a modern, minimalist interface feel.
- Highly responsive grid-based dashboard with sliding right-side panels for forms to preserve data context while editing.
- Subtle slide-and-fade transitions for lateral panel entries and soft state-changes in action buttons using Framer Motion styles.
